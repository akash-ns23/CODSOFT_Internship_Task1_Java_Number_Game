# Number Guessing Game

## Description
A Java console application where the computer generates a random number between 1 and 100, and the user has to guess it within a limited number of attempts.

## Features
- Random number generation
- User input for guessing
- Feedback:
  - Too High
  - Too Low
  - Correct
- Maximum 7 attempts
- Multiple rounds
- Score calculation

## Technologies Used
- Java
- Scanner Class
- Random Class

## How to Run
1. Compile the program:
   javac NumberGame.java

2. Run the program:
   java NumberGame
